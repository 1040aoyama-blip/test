# 株式ポートフォリオ管理アプリ

ブラウザだけで動く、株式ポートフォリオ管理用のシングルページアプリです。ビルドやサーバーは不要です。

## 使い方

`portfolio/index.html` をブラウザで開くだけで使えます。

- **取引を登録**: 買い／売り／配当を、日付・銘柄コード・株数・単価・手数料とあわせて記録します
- **保有銘柄**: 取引履歴から保有株数・平均取得単価（移動平均法）・評価額・評価損益・構成比を自動計算します
- **株価の更新**: 保有銘柄テーブルの「現在値」をクリックして最新の株価を入力します（Enter で確定、Esc でキャンセル）
- **資産配分**: 評価額ベースの構成比をドーナツチャートで表示します
- **サマリー**: 評価額・取得額・評価損益・実現損益・受取配当・トータルリターン
- **エクスポート／インポート**: データを JSON ファイルで保存・復元できます
- **サンプルデータ**: 動作確認用のデモデータを読み込みます

データはブラウザの localStorage に保存されます。別の端末やブラウザに移すときはエクスポート／インポートを使ってください。

## 計算ルール

- 取得単価は移動平均法（買付手数料を取得原価に含める）
- 売却時の実現損益 = 売却代金 − 手数料 − 平均取得単価 × 売却株数
- 配当は受取額 − 税・手数料を計上
- 保有数を超える売却は計算から除外し、画面上部に警告を表示
- 株価未設定の銘柄は平均取得単価で評価

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `style.css` | スタイル（ダークモード・スマホ表示対応） |
| `portfolio.js` | 損益計算ロジック（DOM非依存） |
| `app.js` | 画面描画・操作・保存 |
| `portfolio.test.js` | 計算ロジックのテスト |

## テスト

```sh
node --test portfolio/portfolio.test.js
```
