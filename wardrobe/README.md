# ワードローブ（洋服管理アプリ）

持っている洋服を登録し、タグで整理するブラウザアプリです。ビルドやサーバーは不要で、`wardrobe/index.html` をブラウザで開くだけで使えます。

## できること

- **フォルダで整理**（Gmail のラベルのような左側のフォルダ一覧）
  - 一番上に「すべてのアイテム」、その下に大カテゴリー（トップス・アウター・ボトムス・ワンピース・シューズ・小物）
  - 大カテゴリーの中にサブフォルダ（例: ボトムス → ジーンズ・スラックス・コットンパンツ）
  - 「＋ 新しいフォルダ」で大カテゴリーもサブフォルダも追加可。各フォルダの「…」から名前の変更・並べ替え・削除
  - 大カテゴリーを選ぶとサブフォルダの分も含めて表示。サブフォルダは一覧の上のボタンでも切り替え可
  - スマホでは左上の ☰ からフォルダ一覧を開く
- **アイテム登録**: 洋服の名前を入力し、次の情報を付けます（カードをクリックすると編集・削除）
  - **フォルダ**: 大カテゴリーとサブフォルダ（サブフォルダは任意）
  - **季節**: 春・夏・秋・冬（複数選択可、「オールシーズン」で一括選択）
  - **色**: 白・黒・ネイビーなど（複数選択可、色見本つきで自由に追加可）
  - **その他のタグ**: 「お気に入り」「仕事用」など自由なタグ
  - **メモ**: ブランドや購入時期など
- **一覧表示**: 選んだフォルダの中を **春 → 夏 → 秋 → 冬 → 季節未設定** の順に表示
  - 複数の季節を持つアイテム（例: 春・秋）は、それぞれの季節に表示されます
  - 各季節の中は、フォルダ一覧の並び順（大カテゴリー → サブフォルダ → 名前）で並びます
- **すべてのアイテム**: 季節で分けず、登録順（新しく登録したものが上）の一覧で表示
- **季節で分けるスイッチ**（すべてのアイテム以外のフォルダ）: オフにすると季節の見出しなしで一覧表示（各アイテム1回ずつ、フォルダ順 → 同じフォルダ内は早い季節順 → 名前順）。設定は端末ごとに記憶
- **絞り込み**: キーワード検索、色で絞り込み
- **色の管理**: 「その他」メニューから色の追加・削除
- **エクスポート／インポート**: データを JSON ファイルで保存・復元
- **サンプルデータ**: 動作確認用のデモデータ

以前の形式のデータ（Tシャツ・ニット・パンツなどが同列のカテゴリー）は、読み込み時に自動で大カテゴリーの中へ移ります（例: ニット → トップス › ニット、パンツ › ジーンズ → ボトムス › ジーンズ）。

データはブラウザの localStorage に保存されます。別の端末やブラウザに移すときはエクスポート／インポートを使ってください。

claude.ai の Artifact として公開した場合は、アカウントごとの非公開ストレージに保存され、スマホとPCで同じデータを使えます（`app.js` の `connectRemote`）。アカウントに保存できない人（ログインしていない人や閲覧のみの人）は、自動的にブラウザ保存で動きます。公開用の1ファイル版は、`index.html` に `style.css`・`wardrobe.js`・`app.js` を埋め込んで作ります。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `style.css` | スタイル（ダークモード・スマホ表示対応） |
| `wardrobe.js` | フォルダ構成・季節分け・絞り込み・データ移行などのロジック（DOM非依存） |
| `app.js` | 画面描画・操作・保存 |
| `wardrobe.test.js` | ロジックのテスト |

## テスト

```sh
node --test wardrobe/wardrobe.test.js
```
